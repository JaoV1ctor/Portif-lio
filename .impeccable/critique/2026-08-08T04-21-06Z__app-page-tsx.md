## Overall Impression

O sistema de design está bem desenhado no papel, mas a implementação já derivou dele em dois pontos que atacam exatamente os pilares que o tornam distinto: a Signal Rule (cor só sinaliza estado) foi quebrada por uma terceira cor decorativa, e a "Lógica de Evidência" (toda skill remete a projeto real) está com dado incompleto no TechStack. A maior oportunidade não é visual — é fechar a lacuna entre o que o DESIGN.md promete e o que o código entrega.

## What's Working

- **Terminal.tsx** é componente genuinamente proprietário: parser de comando real, dino game funcional, download de PDF — prova de execução técnica, não decoração.
- **ProjectCard.tsx** implementa literalmente a hierarquia Hook>Result exigida pelo CLAUDE.md (Trophy + resultMetric em destaque).
- Skeleton loading no carrossel de projetos evita layout shift e reforça a narrativa de dados ao vivo via GitHub API.

## Priority Issues

**[P0] Dado de skills incompleto quebra a Lógica de Evidência**
- **Why it matters**: `data/portfolio.ts` tem só 1 skill (TypeScript), mas TechStack.tsx renderiza um marquee infinito duplicando esse único card. Viola o próprio pilar do CLAUDE.md e, pra Jordan (recrutador) em scan de 3s, parece bug/abandono — o oposto de "execução de elite".
- **Fix**: popular `skills` com o stack real (Next.js, React, Tailwind, Node, Python, Gemini, Claude, Cursor, Firebase — ícones já existem em TechStack.tsx).
- **Suggested command**: $impeccable harden

**[P0] Terceira cor (âmbar) viola a Signal Rule do DESIGN.md**
- **Why it matters**: ProjectCard usa âmbar como acento decorativo pra "Client Work", mas globals.css só define azul (foco/ativo) e verde (sucesso), e a regra é explícita: cor só sinaliza estado. Dilui a identidade de 2 cores do "Command Deck" bem no elemento mais visível pra Alex (cliente PJ avaliando trabalho pago real).
- **Fix**: trocar por ícone (ShieldCheck) + badge neutro, ou formalizar âmbar como estado semântico "client-verified" e atualizar o DESIGN.md.
- **Suggested command**: $impeccable colorize

**[P1] Hero abre com 3 decisões simultâneas antes de qualquer prova**
- **Why it matters**: CTA Projetos / CTA Contato / toggle "Ativar Visual 3D" com peso quase igual na primeira dobra. Força decisão de performance no exato momento em que Jordan decide se vale continuar — atrito desnecessário antes do hook.
- **Fix**: rebaixar o toggle 3D a ícone discreto fora da fileira de CTAs primários.
- **Suggested command**: $impeccable layout

**[P1] Filtro de categorias sem cap, com scroll-hijack não padrão**
- **Why it matters**: categorias derivadas dinamicamente das linguagens do GitHub podem passar de 4 chips, forçando scroll horizontal que intercepta wheel. Alex quer filtrar rápido, não decifrar interação não padrão.
- **Fix**: limitar a top-N linguagens + agrupar resto em "Outros", ou trocar por dropdown acima de 4 opções.
- **Suggested command**: $impeccable distill

**[P2] 12 font-sizes de 9-11px fora do type ramp do DESIGN.md**
- **Why it matters**: microtexto espalhado (badges, timestamps, footer) sem ancoragem no scale definido (label = 0.75rem/12px). Sinal de deriva de tokens — cada uso novo tende a inventar mais um valor solto.
- **Fix**: consolidar todos em um token `label-xs` (10px) explícito no DESIGN.md, ou subir pro `label` existente onde a legibilidade permitir.
- **Suggested command**: $impeccable typeset
